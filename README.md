# ✈️ Flight Price Bot — бот для отслеживания цен на авиабилеты

Следит за ценами на Aviasales (через Travelpayouts), присылает уведомление
в Telegram, когда цена падает ниже порога, рисует графики динамики и
управляется кнопками прямо в чате.

## Что умеет

- Несколько маршрутов сразу (по умолчанию: Москва→Анталья, Нижний Новгород→Анталья,
  и Москва→Анталья туда-обратно на 7 дней).
- Отслеживание всей ближайшей недели — берёт минимум по всем дням.
- Билеты в одну сторону и туда-обратно.
- История цен в файле, ежедневный график в Telegram.
- Кнопки в чате: текущие цены, график по запросу, смена порога, статус.

---

## Шаг 1. Что нужно получить (один раз)

1. **Токен Travelpayouts** — регистрация на travelpayouts.com,
   раздел «Разработчикам → API».
2. **Токен Telegram-бота** — напишите @BotFather команду `/newbot`.
3. **Ваш chat_id** — напишите что-нибудь боту @userinfobot, он пришлёт число.

---

## Шаг 2. Настроить

Откройте `bot.py`, в блоке `CONFIG` впишите три токена (или задайте их
через переменные окружения — это надёжнее). Там же при желании поправьте
список `ROUTES`: коды городов, пороги цен, и `trip_days`
(число дней поездки для «туда-обратно», либо `None` для «в одну сторону»).

Коды городов (IATA): Москва = `MOW`, Нижний Новгород = `GOJ`, Анталья = `AYT`.

---

## Шаг 3. Запустить

Выберите ОДИН из трёх вариантов.

### Вариант A. На своём компьютере (для проверки)

```bash
pip install -r requirements.txt
python bot.py
```
Бот работает, пока открыто окно и включён компьютер. Напишите боту `/start`
в Telegram — появится меню с кнопками. Остановить — Ctrl+C.

### Вариант B. Бесплатный сервер Railway или Render (работает 24/7)

Это самый простой способ «чтобы работало само», без своего сервера.

1. Залейте эту папку в репозиторий на GitHub.
2. На railway.app (или render.com) создайте новый проект из этого репозитория.
   Платформа сама увидит `Dockerfile` и соберёт бота.
3. В настройках проекта добавьте переменные окружения:
   `TP_TOKEN`, `TG_TOKEN`, `TG_CHAT_ID`.
4. Задеплойте. Бот пришлёт «🚀 Бот запущен» в Telegram.

> Примечание про историю: на бесплатных планах файловая система может
> сбрасываться при передеплое. Чтобы график не терял историю, подключите
> volume и смонтируйте его в `/data` (переменные `HISTORY_CSV` и
> `SETTINGS_JSON` уже указывают туда в Dockerfile).

### Вариант C. Свой VPS на Linux (systemd)

```bash
# положите файлы в /home/youruser/flightbot, затем:
sudo cp flightbot.service /etc/systemd/system/
# отредактируйте пути, пользователя и токены внутри файла:
sudo nano /etc/systemd/system/flightbot.service

sudo systemctl daemon-reload
sudo systemctl enable flightbot     # автозапуск при загрузке
sudo systemctl start flightbot      # запустить сейчас
sudo systemctl status flightbot     # проверить, что работает
journalctl -u flightbot -f          # смотреть логи в реальном времени
```
`Restart=always` перезапустит бота автоматически при любом сбое.

## Управление в чате

- `/start` — показать меню с кнопками.
- **💰 Текущие цены** — минимум за неделю по всем маршрутам прямо сейчас.
- **📊 График сейчас** — прислать графики немедленно, не дожидаясь утра.
- **🎚 Изменить порог** — выбрать маршрут и ввести новый порог (сохранится в
  `settings.json`, менять код не нужно).
- **ℹ️ Статус** — что отслеживается и с какими порогами.

## Частые вопросы

**Нижний Новгород показывает «нет данных».**
По этому городу у Travelpayouts бывает мало предложений, особенно если нет
прямых рейсов. Это нормально: бот просто пропустит проверку и продолжит.

**Первый график пустой / не приходит.**
Нужно накопить минимум две проверки. За первый день история наберётся,
и графики станут содержательными.

**Цена в боте чуть отличается от сайта.**
Travelpayouts отдаёт цены из кэша поисков — они могут немного отставать от
«живой» цены. Для ловли падений этого достаточно; финальную цену проверяйте
на странице покупки по ссылке из уведомления.

**Безопасность токенов.**
Не публикуйте `bot.py` с вписанными токенами в открытый доступ. Лучше всегда
задавать токены через переменные окружения (варианты B и C так и делают).
